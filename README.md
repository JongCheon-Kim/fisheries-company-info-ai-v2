- Leaflet pane보다 높은 z-index(1200) 적용

- 기본 위치를 휴대폰 우측 상단 안전영역으로 재설정
- 범례의 클릭·휠·드래그 이벤트가 지도 조작으로 전파되지 않도록 차단
- `sw.js` 캐시 버전 상향으로 수정 HTML 즉시 갱신

## v2 주요 수정
1. 지도 상단 `조건` 버튼 제거
2. 지도 조건은 `특허·저장 → 지도 조건 선택`으로 통합
3. 산업부문 범례를 지도 영역 밖으로 분리하여 **휴대폰 전체 화면에서 자유 드래그**
4. 생산 조회연도는 2019, FIS 가공·유통·외식은 2021~2024 표시
5. 재무 건전성·기간별 경영동향 선택 가능
6. 상세정보의 기업 상세·핵심 재무 체크 가능
7. 검색목록 마우스 클릭이 드래그 로직에 막히는 문제 수정
8. 노란색 검색버튼은 Enter와 동일한 form submit 동작 유지
9. 좌표 미확보 주소는 후속 QA 대상으로 분리

## 중요 데이터 상태
FIS 공식 기업상세 화면의 조회 범위는 2021~2024로 확인되어 앱의 조회연도도 그 범위로 제공합니다. 다만 현재 정적 `companies.json`에는 FIS 기업의 **2024 핵심재무 중심**으로 보존되어 있으므로 2021~2023 값이 저장되지 않은 기업은 `-`로 표시됩니다. 임의 값은 만들지 않습니다.

## GitHub Pages
저장소 루트에 이 ZIP의 파일을 모두 업로드하고 `Settings → Pages → Deploy from a branch → main / root`로 배포합니다.

## 좌표 유지보수
`geocode-osm.html`과 `address_queue.json`은 일회성 좌표 보정용입니다. 운영 앱은 외부 지오코딩 API를 호출하지 않고 `coordinates.json`만 읽습니다.


## v2.2 변경사항
- FIS 기업 2021~2024 핵심재무·재무건전성·기간별 경영동향을 Cloudflare Worker로 조회
- FIS 상세정보에 기업상세·핵심재무·손익계산서·재무상태표·현금흐름표 선택 복원
- 검색 부문(생산·가공·유통·외식) 클릭 후 기업목록이 닫히지 않도록 수정
- Worker 실패 시 2024 정적 백업만 표시하며 결측값을 생성하지 않음
